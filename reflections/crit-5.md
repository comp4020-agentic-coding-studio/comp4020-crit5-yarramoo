# Crit 5 reflection

**What was the breakthrough that moved the work forward?**
Rescoping to something simpler. I initially asked claude to make a minecraft clone on max model and effort settings to test it out. But turning it into an easily understandable game that didn't need a tutorial was difficult. 


**What did this work change about who I want to be as a software developer?**
When comparing the manual intervention required to make the minecraft clone vs dash platformer, far less effort was required for the clone. This was because there was a very clear goal and image in mind, vs the platformer was developed iteratively and features chosen during play-testing. More up-front planning and a clearer idea would dramatically reduce dev time and token usage.
